Version 3.13 / パスキー認証
wrangler.jsonc の main は従来通り worker.js。既存D1を維持してデプロイしてください。
追加テーブル・トリガーはDiscordログインまたはパスキーAPIの初回利用時に自動作成します。
管理者・教官ともDiscord認証後の画面で10分以内にパスキーを登録できます。登録は任意です。
次回はログイン画面のパスキーから認証します。HTTPS・同一ホスト名が必要です。
Face ID等の端末本人確認を要求しますが、端末の設定によりPIN等になる場合があります。
利用停止・教官Discord連携解除・教官削除で登録済みパスキーを削除します。
再有効化後はDiscordから再登録してください。ログイン保持は90日です。
Discord更新通知はVersion 3.13では無効。通常の研修通知は変更していません。
検証: worker.js と新規ブラウザスクリプトの Node 構文チェック済み。
実機Safari、Cloudflare D1、Discord OAuthの統合動作は未検証です。本番前にテスト環境で確認してください。
worker-hotfix.js は旧来の補助ファイルで変更なし。デプロイにはworker.jsを使用してください。
