LOMITA POLICE Training Reservation - Version 1.73

修正：承認待ちDiscord通知が1時間ごとに来ない問題

原因
- Version 1.64〜1.72では「前回通知から60分以上経過」で判定
- Cronが数秒ずれると、9:00:15送信 → 10:00:05実行のような場合に
  60分未満となり、10時台の通知をスキップしていた

修正
- 経過60分方式を廃止
- 「時刻の1時間枠ごとに1回」に変更
- 9時台に1回、10時台に1回、11時台に1回…と通知
- 同じ時間帯でCronが再実行されても重複通知しない
- 承認済み / 担当教官決定済み / 希望日時超過は対象外

維持
- @学科講師メンション
- 希望日時超過処理
- 研修生再申請
- 管理ダッシュボード
- 今日/今週/承認待ち/再受講のナビゲーション
