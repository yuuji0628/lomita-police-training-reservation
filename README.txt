LOMITA POLICE Training Reservation - Version 2.30

研修ごとの所要時間設定と終了時刻の自動計算を追加。

管理者画面:
- 「研修プログラム管理」の下に「⏱ 所要時間を設定」
- 研修ごとに15分単位で所要時間を設定
- 15〜480分
- 未設定の研修は既定60分

研修生側:
- 対象研修の所要時間を自動取得
- 教官が登録した空き時間ウィンドウから、15分刻みの開始候補を自動生成
- 所要時間が収まる候補だけ表示
- 各候補は「開始〜終了」を自動表示
- 任意日程でも開始時刻を選ぶと「終了予定」を自動表示

例:
教官空き時間 14:00〜17:00 / 研修所要時間60分
→ 14:00〜15:00, 14:15〜15:15, ... のように候補生成

Version 2.29までの機能を維持。
