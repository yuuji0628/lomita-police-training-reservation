LOMITA POLICE Training Reservation - Version 1.98

30日以内の研修修了ルールを追加

開始基準
- 原則：オリエンテーションを「済」にした日
- 途中参加等でオリエンテーション記録がない場合：最初の研修修了日

期限
- 研修開始日から30日
- 期限日を過ぎても全研修未修了の場合、自動リセット
- 全研修修了済みの研修生は対象外

リセット内容
- 現在の予約・受講進捗を初期化
- オリエンテーションから再スタート
- リセット前の予約/受講データは
  training_cycle_resets / training_cycle_reset_items に自動アーカイブ
- アンケート結果は履歴として保持
- Discord通知は追加しない

研修生画面
- 「研修修了期限」の注意文を常時表示
- 開始前：30日ルールを案内
- 開始後：研修開始日 / 期限日 / 残り日数を表示
- 残り7日以下は注意表示を強調

実行
- 研修生画面を開いた時に即時チェック
- 既存の1時間cronでも自動チェック

Version 1.97までのDiscord通知整理、アンケート必須、管理機能等を維持
