LOMITA POLICE Training Reservation - Version 2.21

追加機能:

1. 「ここは触らない」へ管理者専用ツールを集約
- 🧪 テスト研修生
- 📅 教官の空き時間
- ⏳ 期限延長
- 右下のテスト研修生ボタンは非表示化し、ここから開く

2. 教官の空き時間管理
- 教官を選択
- 日付
- 開始時間 / 終了時間
- メモ
- 登録済み予定一覧
- 削除
- 過去日を除外して今後の空き時間を表示

3. 期限延長
- 研修生を選択
- +3 / +7 / +14 / +30日プリセット
- 0〜90日まで任意指定
- 延長理由
- 0日で延長解除
- 30日期限の表示だけでなく、自動期限リセット判定にも反映

実装:
期限計算に使われる開始日SELECTを安全なDB Proxyで補正するため、
core側の画面表示・管理一覧・定期実行の期限判定すべてに同じ延長日数が適用されます。

Version 2.20までの機能を維持。
