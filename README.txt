LOMITA POLICE Training Reservation - Version 2.39

15分単位なのにエラーになる問題を修正。

原因:
研修生側の画面では「1:30」のように1桁時刻として扱われる場合がありますが、
サーバー側は「01:30」の2桁形式だけを許可していました。
そのため、見た目は正しい15分単位でも保存時にエラーになる場合がありました。

修正:
- 1:30 / 01:30 / 01:30:00 を正しく判定
- サーバー受信時に自動で 01:30 へ正規化
- 00 / 15 / 30 / 45分以外だけを拒否
- 教官側の空き時間登録にも同じ正規化を適用
- Version 2.38の教官確定枠表示修正を維持
