LOMITA POLICE Training Reservation - Version 1.78

追加：予約確定後の「処理待ち」

- 予約確定のまま確定日時を過ぎた研修を「処理待ち」として判定
- 判定は日本時間（JST）
- 管理ダッシュボード常時表示：
  今日の研修 / 承認待ち / 処理待ち / 再受講
- 今週の研修は詳細情報へ移動
- 処理待ちを押すと対象予約だけに絞り込み、自動スクロール
- 対象カードに「処理待ち」バッジと注意文を表示
- 管理者は受講済み / 再受講 / 欠席のいずれかへ処理
- status自体はreservedのままなので既存操作を維持
- 「対応が必要」集計にも処理待ちを含める

Version 1.77までの既存機能を維持
