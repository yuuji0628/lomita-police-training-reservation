LOMITA POLICE Training Reservation - Version 2.15

高優先度運用機能をまとめて追加。

1. D1利用状況
- 実測できる正常/メンテナンス/エラーを表示
- 次回リセット時刻を表示
- 正確な利用率%はCloudflare Analytics認証なしでは取得できないため架空表示しない

2. 事前警告
- 残り時間とD1状態を常設
- D1エラー発生時は自動メンテナンス

3. 予約一覧ページ分割
- 20件/ページ
- 前/次ボタン
- Cookieで現在ページを保持

4. 期限アラート強化
- 7日以下 注意
- 3日以下 警告
- 1日以下 緊急
- 期限順ソートは既存v2.04を維持

5. 今日の対応だけ簡易モード
- 今日の研修 / 承認待ち / 再受講を小型パネル表示

6. Discordまとめ通知
- 毎時cronで今日の研修/承認待ち/再受講を1通に集約
- 対象0件なら送信しない

7. 障害ログ
- incident_logsへ重大エラーを保存
- 管理メニューから直近30件を確認

8. バックアップ表示
- GITHUB_TOKEN/GITHUB_PAT設定時、GitHub最新コミットを「GitHub最終保存」として表示
- DBバックアップそのものと誤認しない表記

Version 2.14までのD1節約/メンテナンス/コンパクトUIを維持。
