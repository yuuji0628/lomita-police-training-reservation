LOMITA POLICE Training Reservation - Version 1.83

今回まとめて対応

1. 教官ランキング修正
- 途中参加による「既修了認定」は教官ランキングから除外
- 旧データの担当教官「既修了認定」も除外
- 通常受講済みとオリエンテーションは実際の担当教官へ加算
- 受講済み取消後はcompletedから外れるため自動でランキングも減少

2. オリエンテーション未のDiscord案内
- オリエンテーション未の研修生が1名以上いる場合、1時間ごとに教官チャットへ案内
- @学科講師メンション対応
- 「オリエンテーションを実施した場合は、実施した講師が管理画面から担当教官を選択して『済』にしてください。」
- 同じ1時間帯の重複通知を防止

3. 管理ダッシュボード
- 詳細情報に「オリエンテーション未」件数を追加
- タップすると未実施の研修生だけ表示

4. 管理画面 / 研修生画面
- 小型カレンダーを追加
- 現在の日付・曜日・時刻を常時表示
- 日本時間（Asia/Tokyo / JST）固定
- 時計は1秒ごとに更新

5. Version 1.82の予約確定時Discord通知を維持
