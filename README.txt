LOMITA POLICE Training Reservation - Version 1.59

追加
- 承認待ち / 担当教官未決定の研修申請をDiscordへ定期通知
- Cloudflare Cronは既存の毎時実行を使用
- 各承認待ち申請ごとに、前回通知から3時間以上経過した場合のみ再通知
- 一度に最大10件をまとめて通知
- @学科講師ロールIDが設定済みなら自動メンション
- 通知文:
  「承認待ちの研修申請があります。担当教官がまだ決まっていません。」
- 研修名 / 研修生 / 第1〜第3希望日時を表示
- Discord通知から管理画面を開けるリンク付き
- 予約が承認等でpendingから外れたら定期通知対象から自動除外

既存機能はVersion 1.58まで維持
