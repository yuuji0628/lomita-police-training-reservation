LOMITA POLICE Training Reservation - Version 2.35

研修生の申請画面に教官確定枠が表示されない問題を修正。

原因:
- 予約モーダルが動的に作られるタイミングと旧マウント判定が合わず、
  日付/時間欄だけ表示されて教官確定枠が挿入されない場合がありました。
- また、研修所要時間60分に対して教官が30分枠を登録していると
  候補0件になる場合がありました。

修正:
- 申請モーダルそのものを検出して、その中へ確実に教官確定枠を挿入
- MutationObserver + click + 1秒再確認で動的モーダルにも対応
- 教官が登録した30分枠も優先候補として表示
- 15分単位の開始時刻を維持
- 任意の別日申請も維持

管理者側の登録済み枠:
- Eve Crow 04:00〜04:30
- Vip Tonakai 02:00〜02:30
のような枠が研修生側に表示される設計。
