LOMITA POLICE Training Reservation - Version 2.38

重要修正:
研修生側で「教官確定枠」が何度修正しても表示されなかった根本原因を修正。

根本原因:
HTMLへ注入しているブラウザJSが1つのasync処理内にまとまっており、
研修生画面で /api/admin/d1-status が401になると
`return` により後続JSがすべて停止していました。

そのため以下が研修生画面で実行されていませんでした:
- 教官確定枠の表示
- 15分単位制御
- 日付変更時の枠再取得
- 所要時間連動
- 終了時刻計算など

Version 2.38:
- D1ステータスが401でも、D1表示だけを消して後続処理を継続
- 研修生用JSが必ず実行されるよう修正
- Version 2.37の「第1希望直下へ教官確定枠」処理をそのまま有効化
- 管理者側の機能は維持
