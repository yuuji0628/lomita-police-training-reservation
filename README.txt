LOMITA POLICE Training Reservation - Version 1.58

追加：途中参加・開始研修指定

管理画面 > 研修生管理
- 各研修生ごとに「この研修から開始」を選択可能
- 選択した研修より前の未修了研修を「既修了認定」として自動登録
- 認定日は任意（空欄でも設定可能）
- 既存の通常受講済み履歴は削除しない
- 過去に設定した「途中参加による既修了認定」だけを再設定時に更新
- 指定した研修から通常どおり申請可能
- 進捗表には通常の修了印ではなく「既修了 / 認定」印を表示
- 管理側進捗表にも「既修了認定」と表示
- 管理上の編入処理なので本人へのDiscord DMは送信しない

Version 1.57までの既存機能を維持
