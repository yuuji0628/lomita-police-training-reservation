LOMITA POLICE Training Reservation - Version 1.53

本採用試験 専用機能

- 「本採用」を含み、かつ「試験」を含む研修を本採用試験として自動判定
- 管理画面に「合格 / 不合格」判定ボタンを表示
- 0〜100点の得点を任意入力可能
- 合格:
  - status = completed
  - 研修進捗表は修了扱い
  - 本人へDiscord DMで「正式にLOMITA POLICEへ本採用」と通知
- 不合格:
  - status = retake
  - 修了扱いにしない
  - 本人へ「再度内容を復習し、教官の指示に従って再受験をお願いします」とDM
- 受講済み履歴にも判定・得点を表示
- 得点は未入力でも保存可能
- 得点入力時は0〜100の整数のみ

Version 1.52までの既存機能を維持
