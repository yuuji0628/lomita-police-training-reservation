LOMITA POLICE Training Reservation - Version 2.25

緊急修正:
研修生ポータルに「管理者専用ツール」「テスト研修生」「期限延長」が表示される問題を修正。

対策:
- 「ここは触らない」の管理者専用ツールは /api/admin/check 成功時のみ表示
- 研修生ポータル判定時は管理者ツールを強制非表示
- 「研修管理本部 / システム管理者 / ADMIN TOOLS」表示がある管理画面だけ許可
- 「予約一覧」下の「空き時間を登録」ボタンも管理者画面だけに限定
- 既に誤表示されている管理者ツールは研修生画面で自動削除

維持:
- 管理画面のテスト研修生
- 期限延長
- 教官の空き時間登録
- 研修生側の教官確定枠（優先）
