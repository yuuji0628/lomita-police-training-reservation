LOMITA POLICE Training Reservation - Version 2.31

開始時刻選択と終了時刻の自動表示を改善。

教官側:
- 開始時刻は15分刻みの選択式
- 00 / 15 / 30 / 45分のみ
- 終了時刻の入力欄を削除
- 開始時刻を選ぶと終了時刻を自動表示
- 基本は「開始 + 30分」
- 保存時も自動計算した終了時刻を使用

研修所要時間:
- 未設定時の既定値を30分へ変更
- 管理者が研修ごとに所要時間を変更可能
- 研修生側の終了時刻は設定された所要時間から自動計算

例:
開始 14:15 → 終了 14:45
開始 23:45 → 終了 00:15

Version 2.30までの機能を維持。
