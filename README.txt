LOMITA POLICE Training Reservation - Version 2.33

教官の空き時間登録で、15分単位の開始時刻を選んでも
「開始時刻を15分単位で選択してください」と出る不具合を修正。

原因:
終了時刻を画面表示用datasetから取得していたため、
iPhone Safariの時刻選択UIでchangeイベントが期待どおり反映されない場合、
終了時刻が空のまま保存チェックに入り、誤った警告が出ていました。

修正:
- 開始時刻のinput/change両方で終了時刻を更新
- 保存時は開始時刻から終了時刻を直接 +30分計算
- datasetに依存しない
- 21:30 → 22:00 のように確実に自動計算
- Version 2.32のコンパクトUIも維持
