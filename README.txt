LOMITA POLICE Training Reservation - Version 2.36

管理者側で登録済みの教官空き時間が、研修生側で
「この研修を完了できる教官確定枠はありません」と表示される問題を修正。

修正:
- 研修生用APIのSQLite日付/時刻フィルタ依存を廃止
- JSTで現在日時を判定
- 今日の枠は終了済みだけ除外
- 15分単位の枠だけ使用
- 研修生が第1希望の日付を選ぶと、その日の教官確定枠だけを即再表示
- 教官枠に研修所要時間が収まる場合だけ「確実な枠」として表示
- 例: 2026-09-13 01:30〜02:00 / 所要30分 → 候補表示
- 別日申請も維持

Version 2.35までの機能を維持。
