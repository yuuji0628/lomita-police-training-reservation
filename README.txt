LOMITA POLICE Training Reservation - Version 2.34

iPhone Safariの時刻選択で、02:00など正しい15分単位を選んでも
「15分単位で選択してください」と出る問題を修正。

原因:
ブラウザへ注入するJavaScriptが外側のテンプレート文字列内にあり、
正規表現の \d が実行時に正しく残らないケースがありました。
そのため 02:00 を正しく判定できず、終了時刻も --:-- のままになっていました。

修正:
- 正規表現依存を廃止
- 時刻を「:」で分割して数値判定
- 00 / 15 / 30 / 45分を確実に判定
- 02:00 → 02:30 を即時表示
- 保存時も開始時刻から終了時刻を直接+30分計算
- iPhone Safariでも安定して動作
- Version 2.33までの機能を維持
