LOMITA POLICE Training Reservation - Version 1.80

追加：別の希望日時候補で再承認

対象
- すでに予約確定済み
- 確定日時を過ぎている
- 第1〜第3希望の中に「現在の確定日時とは別の未来候補」が残っている

管理画面
- 対象カードに「別候補で再承認」ボタンを表示
- 承認する日時から第2/第3希望などを選択
- 現在の確定候補と同じ候補は不可
- 過去日時の候補も不可
- 担当教官を維持または変更して再承認可能

Discord
- 再承認時に本人へ専用DM
- 変更前日時 / 新しい確定日時 / 担当教官を通知

既存
- 通常の「変更を保存」による予約内容変更も維持
- Version 1.79までの表示修正・処理待ち・取消機能を維持
