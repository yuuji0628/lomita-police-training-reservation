管理ダッシュボード簡略化

常時表示する項目を4つだけに整理
- 今日の研修
- 承認待ち
- 教官未決定
- 再受講

「詳細情報を見る」を開いた時だけ表示
- 今週の研修
- 希望日時超過
- 登録研修生
- 研修中・未修了
- 全研修修了
- 再受講あり

- 「対応が必要」集計カードを常時表示から削除
- 希望日時超過は対応項目ではなく詳細情報へ移動
- iPhoneで縦に長くなりすぎない構成へ変更
- 各数字のタップ絞り込み機能は維持
