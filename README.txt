LOMITA POLICE Training Reservation - Version 2.29

研修生予約画面をスマホ向けに再整理。

変更:
- 教官確定枠を第1希望の直下に横幅100%で表示
- 1列表示に統一
- 日時 / 担当教官 / 選択ボタンを簡潔に表示
- 教官確定枠を選ぶと、第1希望の日付・時間欄は隠してスッキリ表示
- 「別の日程を希望する」を押した時だけ、第1希望の日付・時間欄を表示
- 選択中の枠を緑の確認表示で明確化
- 15分単位ではない旧データ（例 07:13〜15:14）は研修生側の確定枠から除外
- 15分単位ルールは維持
- 過去日選択禁止も維持

Version 2.28までの機能を維持。
