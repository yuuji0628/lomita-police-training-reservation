LOMITA POLICE Training Reservation - Version 2.19

テスト研修生カードが出ない問題を修正。

原因:
管理メニューの見出しがDOM内に複数存在し、v2.18では非表示テンプレート側の「管理メニュー」を先に拾う場合がありました。
その結果、カードは作られていても見えない場所へ入っていました。

修正:
- 画面上で現在表示中の「管理メニュー」を優先して検出
- 既にカードが非表示側に作られていた場合も、表示中モーダルへ自動移動
- 管理メニュー開閉をMutationObserverとクリックで再検知
- TESTバッジがJSTバー等へ誤表示される問題を修正
- TESTバッジは研修生カードだけに限定

Version 2.18までの機能を維持。
