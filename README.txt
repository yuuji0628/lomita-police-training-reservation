LOMITA POLICE 研修管理システム Version 2.42

修正内容
- 「空き時間を登録」を押しても
  「空き時間管理を読み込み中です。もう一度押してください。」
  が何度も出る不具合を修正
- 原因:
  初回表示時に管理者セッション復元より先に空き時間管理の初期化処理が走り、
  そのまま処理が終了していたため
- 管理者認証が完了するまで自動再試行
- 管理画面DOMが表示されるまで待ってから空き時間管理を初期化
- ボタンを押した時も最大4秒間自動待機し、準備完了後そのまま画面を開く
- 「もう一度押してください」を繰り返す必要をなくした

Version 2.41 の修正も維持
- 初回から空き時間ボタン表示
- 講師回数ランキング修正
- 受講済み履歴のHTML文字表示修正

既存設定
- Cloudflare main: worker-hotfix.js
- D1 / Secrets / Variables の変更不要
