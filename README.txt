LOMITA POLICE Training Reservation - Version 2.18

テスト研修生カードが管理メニューに表示されない問題を修正。

原因:
管理メニューはページ読み込み後にモーダルとして開くため、
v2.17では初回スクリプト実行時に「管理メニュー」見出しがまだ存在せず、
テスト研修生カードを挿入できない場合がありました。

修正:
- 管理メニューが後から開かれても自動検知
- MutationObserver + 短時間リトライで確実にカードを追加
- 「管理メニュー」見出し直下に「🧪 テスト研修生」を表示
- 作成 / パスワード再発行 / 進捗リセット / 削除を維持

Version 2.17までの機能を維持。
