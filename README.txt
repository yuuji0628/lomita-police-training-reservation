LOMITA POLICE Training Reservation - Version 1.44

追加機能
- 予約確定後の内容変更通知
  - 確定日時を変更
  - 担当教官を変更
  - 承認する希望日時を変更
  のいずれかが発生した場合、研修生本人へDiscord DMを自動送信

- キャンセル通知
  - 管理画面の予約ステータスに「キャンセル」を追加
  - キャンセル保存時、研修生本人へDiscord DMを自動送信
  - 再保存による同一ステータス通知は送らない

- 予約確定DM
- 受講済みDM
- 欠席DM
- 前日リマインド
- 当日リマインド
- 研修ポリシー確認・同意必須
- 受講日表示
- Discord研修申請通知
- GitHub ZIP更新
