LOMITA POLICE v3.12 — Discordログイン90日保持

変更点:
- Discord管理者ログイン: 90日間有効なHttpOnly/Secure/SameSite CookieとD1セッション
- Discord教官ログイン: 同じく90日間
- 管理者の利用停止: active=0で毎リクエスト拒否し、対象のセッションをD1から削除
- 教官の利用停止: 管理画面でDiscord IDの連携を解除（空欄にして保存）。対象のD1セッションを削除
- 明示的ログアウト: D1セッション削除、Cookie失効
- バージョン表示: 3.12

重要:
- 90日は最終ログインからの固定期限です（アクセスするたびの自動延長ではありません）。
- DiscordのOAuth認証自体を90日保持するのではなく、アプリ独自のログインセッションを保持します。
- 管理者の個人ID/パスワードログインの12時間期限は変更しません。
- 旧共通パスワードなど他の認証経路が残る場合、その経路は別途無効化しない限り使える可能性があります。
- 教官の紐付け解除は既存の教官レコードや研修予約を削除しません。
- 公開環境での実動作は未検証です。D1バックアップ後、テスト環境で確認してください。

更新: ZIP内のworker.jsをデプロイ。Cloudflare Secrets/D1の設定は引き継いでください。
